One word, the word my ex would use to describe me: **rehearsal**.

I thought I was the main event. Turns out I was the dress rehearsal —
the practice run before the real thing. Painfully true, and I know it.

## Run it

```sh
python3 main.py
```

The program writes exactly one word to `/output/entry.txt` (UTF-8, no
trailing newline), with a fail-fast guard (1–24 characters, not only white
space, exactly one word) before writing and a round-trip assert after
writing. Standard library only.
